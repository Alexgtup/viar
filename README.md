# WebXR / Three.js AR prototype

Небольшой браузерный AR-прототип на Three.js и WebXR. Страница загружает GLB/GLTF-сцену, создаёт WebGL renderer и камеру, подключает OrbitControls и пытается открыть `immersive-ar` session на совместимом устройстве.

## Что находится в репозитории

- `index.html` — браузерная сцена и WebXR-логика;
- `fire_scene.glb` / `fire_scene.gltf` — 3D-сцена;
- `marker.jpg` — изображение маркера;
- `manifest.xml` — вспомогательный manifest.

## Технологии

`JavaScript` · `Three.js` · `WebGL` · `WebXR` · `GLTF/GLB`

Это экспериментальный прототип, а не production AR-приложение. Он показывает работу с 3D-сценой и браузерными XR API без отдельного backend.
